# Runbook

Use this runbook when preparing a local agent context bundle.

1. Confirm the worktree contains only files relevant to the task.
2. Run the context budget check from the repository root.
3. Inspect category totals before adding more source excerpts.
4. Remove duplicate background material if the docs category is over budget.

## Recovery

If the budget is exceeded, prefer deleting generated output and copied logs
before removing concise project documentation. Generated artifacts usually carry
many tokens while adding little decision value.
